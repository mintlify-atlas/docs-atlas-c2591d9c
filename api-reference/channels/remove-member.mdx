---
title: "Remove member"
description: "Remove a specific user from a channel. Only the channel owner can perform this action."
---

Removes a single user from a channel. The authenticated user must be the owner of the channel.

```http
POST /api/rpc/chat/channel/{uuid}/remove-member
```

## Request

<ParamField path="uuid" type="string" required>
  UUID of the channel to remove the member from.
</ParamField>

<ParamField body="memberId" type="string" required>
  User ID of the member to remove.
</ParamField>

## Response

Returns `204 No Content` on success. No response body is returned.

## Error codes

| Code | Description |
|------|-------------|
| `UNAUTHORIZED` | No valid session cookie was provided. |
| `FORBIDDEN` | You are not the owner of this channel. |

## Example

```typescript
import { orpc } from "@/lib/orpc-client";
import { useMutation } from "@tanstack/react-query";

const { mutate: removeMember } = useMutation(
  orpc.chat.channel.removeMemberFromChannel.mutationOptions()
);

removeMember({
  uuid: "018e4c7f-3b2a-7000-8abc-def012345678",
  memberId: "user_abc123",
});
```
