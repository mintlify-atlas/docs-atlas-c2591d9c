---
title: "Add members"
description: "Add one or more users to a channel. Only the channel owner can perform this action."
---

Adds one or more users to an existing channel. The authenticated user must be the owner of the channel. Each user in `memberIds` is added with the `member` role.

```http
POST /api/rpc/chat/channel/{uuid}/add-members
```

## Request

<ParamField path="uuid" type="string" required>
  UUID of the channel to add members to.
</ParamField>

<ParamField body="memberIds" type="string[]" required>
  Array of user IDs to add to the channel.
</ParamField>

## Response

Returns `204 No Content` on success. No response body is returned.

## Error codes

| Code | Description |
|------|-------------|
| `UNAUTHORIZED` | No valid session cookie was provided. |
| `FORBIDDEN` | You are not the owner of this channel. |

## Example

```typescript
import { orpc } from "@/lib/orpc-client";
import { useMutation } from "@tanstack/react-query";

const { mutate: addMembers } = useMutation(
  orpc.chat.channel.addMembersToChannel.mutationOptions()
);

addMembers({
  uuid: "018e4c7f-3b2a-7000-8abc-def012345678",
  memberIds: ["user_abc123", "user_def456"],
});
```
