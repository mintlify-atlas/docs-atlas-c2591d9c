<Note>
  You need a running PostgreSQL database before starting. If you don't have one, you can provision a free database on [Neon](https://neon.tech) or run one locally with Docker.
</Note>

## Prerequisites

Before you begin, make sure you have the following installed:

- **[Bun](https://bun.sh)** v1.0 or later — used as the runtime, package manager, and task runner
- **[Node.js](https://nodejs.org)** v18 or later — required by some build tooling (Vite)
- **PostgreSQL** — the application uses Drizzle ORM with a PostgreSQL database

## Setup

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/aldotestino/hono-orpc.git
    cd hono-orpc
    ```
  </Step>

  <Step title="Install dependencies">
    Install all workspace dependencies from the monorepo root. Bun workspaces resolve packages across all apps and packages automatically.

    ```bash
    bun install
    ```
  </Step>

  <Step title="Configure environment variables">
    Create a `.env` file in `packages/db/` for database access and in `apps/api/` for the API server.

    **`packages/db/.env`**
    ```bash
    DATABASE_URL="postgresql://user:password@localhost:5432/hono_orpc"
    ```

    **`apps/api/.env`**
    ```bash
    DATABASE_URL="postgresql://user:password@localhost:5432/hono_orpc"
    GOOGLE_CLIENT_ID="your-google-client-id"
    GOOGLE_CLIENT_SECRET="your-google-client-secret"
    OPENROUTER_API_KEY="your-openrouter-api-key"
    ```

    | Variable | Description |
    |----------|-------------|
    | `DATABASE_URL` | PostgreSQL connection string |
    | `GOOGLE_CLIENT_ID` | OAuth 2.0 client ID from the [Google Cloud Console](https://console.cloud.google.com) |
    | `GOOGLE_CLIENT_SECRET` | OAuth 2.0 client secret from the Google Cloud Console |
    | `OPENROUTER_API_KEY` | API key from [OpenRouter](https://openrouter.ai/keys) for AI model access |
  </Step>

  <Step title="Run database migrations">
    Apply the Drizzle ORM migrations to set up all tables in your database:

    ```bash
    bun run db:migrate
    ```

    This runs `drizzle-kit migrate` inside `packages/db` and creates all required tables.
  </Step>

  <Step title="Start the API server">
    Start the Hono backend with file-watching enabled:

    ```bash
    bun run api
    ```

    The API server starts at `http://localhost:3000`. It also serves the compiled frontend in production mode. The interactive OpenAPI reference is available at `http://localhost:3000/api/rpc/reference`.
  </Step>

  <Step title="Start the web dev server">
    In a separate terminal, start the Vite development server for the React frontend:

    ```bash
    bun run web
    ```

    The web app opens at `http://localhost:3001` with hot module replacement enabled.
  </Step>

  <Step title="Open the app">
    Navigate to `http://localhost:3001` in your browser. You can sign up with an email and password or use **Sign in with Google** (requires your OAuth credentials to be configured).
  </Step>
</Steps>

<Tip>
  Use **Drizzle Studio** to visually inspect and edit your database while developing:

  ```bash
  bun run db:studio
  ```

  This opens Drizzle Studio in your browser with a live view of all tables and their data.
</Tip>
