## What is Hono oRPC Chat?

Hono oRPC Chat is a production-grade full-stack chat application built as a showcase of the latest TypeScript ecosystem libraries. It demonstrates best practices for building type-safe, real-time applications where types flow seamlessly from the database all the way to the UI.

The project is a monorepo using Bun workspaces, with a Hono backend, React frontend, and shared packages for database and AI utilities.

## Architecture overview

The application follows a contract-first API design pattern:

1. **Contracts** define the shape of every API call using Zod schemas and oRPC's `oc` builder
2. **Handlers** implement the contracts with full type inference from the contract definition
3. **Client** uses the same contract to generate type-safe TanStack Query hooks automatically

This means a change to an API contract instantly produces a TypeScript error at every affected call site — frontend and backend — before any code runs.

```
Contract (Zod + oRPC) → Handler (Hono) → Client (TanStack Query)
         ↑                                        ↑
         └──────── Shared type inference ─────────┘
```
